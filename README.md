# Learnify LMS

Learnify is a full-stack Learning Management System (LMS) built with Spring Boot and React.

## Tech Stack

- Backend: Spring Boot, Spring Security, JWT, JPA
- Frontend: React
- Database: MySQL
- Build Tool: Maven
- API Documentation: Swagger/OpenAPI

## Features

- Role-Based Authentication (Admin, Instructor, Student)
- Course Management
- Lesson Management
- Student Enrollment
- Progress Tracking
- Media Upload
